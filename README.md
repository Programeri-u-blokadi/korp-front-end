
## Preduslovi

- Node.js (v14 ili noviji)
- npm

## Instalacija

1. Klonirajte repozitorijum:
   ```bash
   git clone <URL_REPOZITORIJUMA>
   ```
2. Pređite u direktorijum projekta:
   ```bash
   cd korp-front-end
   ```
3. Instalirajte zavisnosti (bez peer deps grešaka):
   ```bash
   npm install --legacy-peer-deps
   ```

## Pokretanje u razvojnom režimu

```bash
npm run dev
```

Nakon toga aplikacija će biti dostupna na adresi http://localhost:3000
